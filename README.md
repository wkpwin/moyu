# 桌面小说阅读器

## 项目概述
本项目是一个简单的Windows桌面小说阅读应用，支持用户不安装任何依赖即可使用。应用具备悬浮球功能，用于控制阅读区域的显示和属性设置。

## 主要功能
- 支持打开和阅读txt格式小说文件
- 悬浮球控制阅读区域
  - 调整阅读区域透明度
  - 显示/隐藏阅读区域
  - 全局置顶功能
- 阅读历史记录
  - 自动记录上次阅读位置
  - 在文件历史列表中突出显示最近阅读的文件

## 技术栈
- 编程语言: Python
  - 版本要求: Python 3.7+
  - 优势: 开发效率高，跨平台支持
- GUI库: Tkinter
  - 可行性验证:
    * 支持Toplevel窗口实现悬浮球
    * 支持窗口透明度设置(attributes('-alpha'))
    * 支持全局置顶(attributes('-topmost'))
    * 支持窗口拖动功能
- 打包工具: PyInstaller
  - 可行性验证:
    * 支持打包为独立exe文件
    * 支持包含资源文件
    * 支持隐藏控制台窗口(--windowed)
- 数据存储: JSON
  - 可行性验证:
    * 适合存储简单的键值对数据
    * Python标准库支持
    * 易于读写和维护

## 模块设计
### 模块化设计
#### 对象模块
- 定义主界面、显示区域和悬浮球的类
- 确保每个类职责单一，高内聚低耦合
- 代码独立性保证：
  - 每个类单独文件存放
  - 使用接口定义类间交互
  - 通过依赖注入方式使用其他模块

#### 事件模块
- 处理用户交互事件，如文件选择、悬浮球点击等
- 确保事件处理逻辑清晰，响应迅速
- 代码独立性保证：
  - 使用事件总线机制
  - 事件处理函数独立封装
  - 事件与业务逻辑解耦

#### 通信模块
- 管理对象之间的通信，确保悬浮球能控制显示区域
- 采用回调函数或观察者模式实现通信
- 代码独立性保证：
  - 定义标准通信接口
  - 使用中间件处理通信
  - 通信模块与业务逻辑分离

### 主界面 (MainInterface类)
- 文件上传和选择功能
- 展示打开过的文件历史记录
- 启动阅读模式

### 阅读区域 (ReadingArea类)
- 显示小说内容
- 支持透明度调整
- 支持显示/隐藏
- 可拖动并全局置顶

### 悬浮球 (FloatingBall类)
- 控制阅读区域显示属性
- 可拖动并全局置顶

## 使用方法
1. 运行应用后上传本地的txt文件，在文件列表（显示历史所有打开过的文件）中选择一个文件单机打开，进入阅读模式
2. 使用悬浮球控制阅读区域：
   - 点击按钮调整透明度
   - 点击按钮显示/隐藏阅读区域
   - 拖动悬浮球到合适位置
3. 关闭应用时会自动保存阅读进度

## 开发环境

- Tkinter (Python标准库)
- PyInstaller

## 打包说明


## 项目结构
```
novel_reader/
├── main.py                  # 主程序入口，负责初始化应用和启动主循环
├── core/                    # 核心模块
│   ├── interfaces/          # 接口定义
│   │   ├── __init__.py      # 接口模块初始化文件
│   │   ├── reader_interface.py  # 定义阅读器核心功能接口
│   │   └── event_interface.py   # 定义事件处理相关接口
│   ├── objects/             # 对象模块
│   │   ├── main_interface.py    # 主界面实现，处理文件选择和历史记录
│   │   ├── reading_area.py      # 阅读区域实现，负责内容显示和样式控制
│   │   └── floating_ball.py     # 悬浮球实现，提供快捷控制功能
│   ├── events/              # 事件模块
│   │   ├── event_bus.py     # 事件总线实现，负责事件分发
│   │   ├── file_events.py   # 文件相关事件处理
│   │   └── ui_events.py     # 用户界面事件处理
│   └── communication/       # 通信模块
│       ├── callback_manager.py  # 回调函数管理
│       └── observer.py      # 观察者模式实现
├── history.json             # 阅读历史记录，存储用户阅读进度
└── resources/               # 资源文件
    ├── icons/               # 图标资源
    │   ├── app.ico          # 应用图标
    │   └── ball.png         # 悬浮球图标
    └── config.ini           # 配置文件，存储应用设置
```
